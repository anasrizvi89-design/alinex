# Working with the owner of Alinex

- Do the work yourself. Don't hand the owner to-do steps or ask routine questions.
- Only ask the owner about sensitive things: passwords, payments, personal details, account logins, or anything public that can't be undone.
- Keep the owner's personal details (email, etc.) private.
- Apps are listed in `apps.json`; the domain plan is in README.md.
- Domain decision: alinex.eu.org with Cloudflare DNS. Steps are in docs/domain-setup.md. When the owner says it's approved, add a `CNAME` file containing `alinex.eu.org` to the repo root and push. Don't add it before approval, or the github.io address will redirect to a domain that doesn't work yet.
